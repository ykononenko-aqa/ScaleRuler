# ScaleRuler

Инструмент для наложения масштабной линейки на фотографии.  
Предназначен для археологов и других специалистов, публикующих снимки находок.

## Инструкция по использованию

### 1. Запуск программы
Дважды щёлкните по ярлыку ScaleRuler на рабочем столе. Откроется окно программы.

### 2. Загрузка фотографии
Нажмите кнопку **«Загрузить фото»** в верхней части окна (синяя полоса) или большую кнопку в нижней части.  
Выберите файл фотографии на компьютере (форматы JPG, PNG, BMP). Фото появится в центре окна.

### 3. Расстановка точек
Нажмите кнопку **«Перейти в режим расстановки точек»**.  
Щёлкните мышью по фотографии в том месте, где хотите поставить первую точку. Появится зелёный кружок.  
Нажмите кнопку **«Сохранить первую точку»** — кружок станет меньше и зафиксируется.  
Щёлкните в другом месте — появится второй зелёный кружок.  
Нажмите **«Сохранить вторую точку»**. Теперь у вас есть две зафиксированные точки.

> **Важно:** точки должны отмечать объект известного размера (например, отрезок линейки, масштабную метку микроскопа, монету).

### 4. Ввод расстояния
После сохранения второй точки в нижней части окна появится поле ввода.  
Введите расстояние между точками (только цифры, можно с точкой, например `5` или `1.5`).
Для ввода дробных чисел используйте точку, не запятую.
Рядом с полем ввода выберите единицу измерения: **мм**, **см**, **м** или **км**.  

Далее задайте параметры самой линейки:
- **Ячеек** — сколько клеток (делений) будет в линейке (например, `5`);
- **Цена деления** — сколько единиц измерения приходится на одну ячейку (например, `1`).

Длина линейки равна произведению этих значений: `ячейки × цена деления`.  
Нажмите кнопку **«Рассчитать и вывести линейку»**.

### 5. Размещение линейки
На фотографии появится масштабная линейка (бело-чёрные полоски).  
Вы можете **перетащить линейку** в любое удобное место, зажав её левой кнопкой мыши.  
Для быстрого перемещения в угол используйте кнопку со стрелками (рядом с кнопкой «Сохранить изображение»). Квадрат из четырёх частей — это углы фотографии. Нажмите на нужную стрелку, и линейка переместится в соответствующий угол.

Чтобы расположить линейку вертикально, нажмите кнопку со стрелкой **↕** (рядом с угловыми кнопками). Деления при этом идут снизу вверх, а подписи разворачиваются вдоль линейки. Кнопка **↔** возвращает линейку в горизонтальное положение.

Внешний вид линейки можно изменить с помощью выпадающего списка рядом с кнопкой ориентации. Доступны четыре стиля: **«Клетки»** (чередующиеся чёрно-белые клетки), **«Клетки (белые подписи)»** (то же самое, но подписи, вынесенные за линейку, белые), **«Чёрные зарубки»** и **«Белые зарубки»** (полоса снизу с зарубками соответствующего цвета).

### 6. Сохранение результата
Нажмите кнопку **«Сохранить изображение»**.  
Выберите папку и имя файла. Фотография будет сохранена с линейкой (точки не сохраняются).

### 7. Пакетная обработка (для опытных пользователей)
Если у вас много фотографий, сделанных при одинаковых настройках камеры, можно обработать их все сразу.  
Обработайте первую фотографию (шаги 1–6).  
Вместо сохранения нажмите кнопку **«Пакетная обработка»**.  
Выберите папку с исходными фотографиями и папку для сохранения результатов.  
Нажмите **«Запустить»**. Все фото в папке будут обработаны с той же линейкой в том же месте.  
Дождитесь сообщения «Готово» и нажмите **«Закрыть»**.

### 8. Выход из программы
Нажмите кнопку **«Выход»** в верхней синей полосе или закройте окно программы.

## Функции

- Загрузка фото (JPG, PNG, BMP)
- Расстановка двух точек и задание расстояния между ними
- Выбор единиц измерения (мм, см, м, км)
- Настройка линейки: количество ячеек и цена деления (длина = ячейки × цена деления)
- Подписи первого и последнего деления линейки (если деление одно — подписывается только оно)
- Четыре стиля отрисовки линейки: «Клетки», «Клетки (белые подписи)» (для тёмных фото), «Чёрные зарубки», «Белые зарубки»
- Подписи, не помещающиеся в ячейку, выносятся за габарит линейки и учитываются при установке в угол
- Переключение ориентации линейки: горизонтальная или вертикальная (деления снизу вверх)
- Перетаскивание линейки мышью
- Быстрое перемещение линейки в углы изображения
- Сохранение результата в PNG (с подписями)
- Пакетная обработка: применение линейки с одинаковыми параметрами ко всем фото в папке

## Ограничения

- Высота линейки всегда 0.5 единицы; в вертикальном положении длина откладывается по вертикали
- Подписи, вынесенные за линейку, рисуются поверх фотографии цветом стиля (в «Клетки» — чёрным, в «Клетки (белые подписи)» — белым, в зарубках — цветом зарубок)
- При пакетной обработке все фото должны иметь одинаковый масштаб (одинаковые настройки камеры)
- Поддерживаются только форматы JPG, PNG, BMP
- Подписи на линейке видны только на сохранённом изображении, не в окне программы

---

## Известные проблемы

- Подписи на линейке не отображаются в окне программы (только на сохранённом файле)
- Скорость пакетной обработки примерно 1 файл в секунду

## Системные требования

- Windows 10 или новее
- Установщик MSI

## Сборка из исходников

1. Открыть проект в IntelliJ IDEA
2. Выполнить `Gradle → Tasks → compose desktop → packageMsi`
3. Установщик будет в папке `build/compose/binaries/main/msi/`
